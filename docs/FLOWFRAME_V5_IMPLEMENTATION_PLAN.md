# FLOWFRAME v5 动效控制台与视觉强化实施计划

状态：已完成，等待用户视觉确认  
适用范围：桌面端 1280×720 至 1920×1080  
禁止事项：不提交、不推送、不发布；不修改 `.claude/` 和 `XXQ本地资料/`。

## 1. 本轮目标

在保留五个默认作品、三片段循环、声音逻辑和现有详情体验的基础上，完成：

1. 强化主页立体画框对鼠标的吸附、倾斜和纵深运动。
2. 增加跨路由保留的左上角图形控制台，实时调节关键动效参数，并管理作品、封面、短片和音乐。
3. 封面切换时，让动态网络完整变形成另一套带三维空间运动的拓扑。
4. 提高主页、详情页、INFO 和边角导航文字的视觉权重。
5. INFO 打开后背景短片继续播放和循环，只锁定作品切换。
6. PLAY 圆形按钮增加从鼠标位置扩散的黑色墨滴，鼠标离开时弹性回弹。

用户已经确认：

- 本地媒体存入浏览器 IndexedDB，刷新后继续可用。
- 参数和素材修改立即预览，但必须点击保存才长期生效。
- 墨滴只在 PLAY 圆形内部扩散，不覆盖全屏。

## 2. 数据与公共接口

### 2.1 项目 v5

- 项目配置升级到版本 5。
- 只迁移仍等于旧默认值的参数；用户修改过的数值保留。
- 关键参数统一由 `src/data/motion-schema.js` 定义，控制台和 Studio 共用。

参数分组：

- 主页：原有镜头和吸附参数，加 `homePosterSwitchKick`、`homePosterSpring`、`homePosterDrag`，控制切换起始冲量与回弹。
- 网络：原有形态、深度、旋转和浮动强度，加 `networkFloatSpeed`、`networkPointerInfluence`、`networkMorphAttack`、`networkMorphElastic`、`networkMorphDamping`、`networkForegroundDepth`。
- 详情转场：原有时长、扭曲、缩放、模糊、切面和文字延迟，加 `transitionSpring`、`transitionDamping`、`transitionWaveStrength`、`transitionWaveFrequency`、`transitionRowDelay`、`transitionDepthShift`。
- PLAY：`playInkDelay`、`playInkDuration`、`playInkElastic`、`playInkDistortion`。

### 2.2 全局控制台

- 控制台挂载在路由根节点外，不随首页、详情、实验页或 Studio 路由销毁。
- 左上角保留一个图形开关；面板默认收起，打开状态存入 `sessionStorage`。
- 面板包含 `MOTION` 和 `MEDIA` 两页。
- 控制台以可读性为先：宽度在约 440–580px 之间随桌面视口变化；2K 屏使用更宽面板和约 12px 的参数文字，缩放笔记本仍保持约 11px 的参数文字。面板高度受视口限制，不遮住浏览器底部。
- MOTION 的 36 项继续双列分组，但不再为强行单页显示而压缩字体。内容区使用独立纵向滚动，底部保存操作始终可见。
- MEDIA 顶部一次选择一个作品，短片区一次选择一个片段；不同时展开五个作品和全部片段。封面、音乐和当前片段可预览、替换、排序与删除，内容较多时在面板内部滚动。
- 每个动效参数同时提供 range 和 number 输入，双向同步、限制范围、实时预览。
- 控制台滚轮不切换作品；输入按键不触发页面快捷键。
- Escape 优先关闭控制台，然后才处理 PLAY、INFO 等页面状态。
- 草稿跨路由保留；显示未保存状态；保存、撤销、恢复默认明确分开。
- 保留 `#/studio`，但 Studio 与控制台使用同一参数定义和 CRUD 模型。

### 2.3 本地媒体

- IndexedDB：`flowframe-media-v1`，对象仓库：`assets`。
- 记录字段：`id`、`kind`、`name`、`mimeType`、`size`、`blob`、`createdAt`。
- 项目内本地媒体引用格式：`idb://flowframe/<asset-id>`。
- 普通项目路径和网络 URL 原样使用。
- 首页海报、详情视频、PLAY、BGM 和控制台预览统一通过素材解析器读取。
- 对象 URL 在素材删除、替换或页面销毁时准确释放。
- 草稿删除不立即删 Blob；显式保存时清理不再引用的本地素材，保证撤销安全。
- JSON 只导出配置和本地引用，不包含二进制；跨浏览器缺失的本地引用显示为 `missing` 并使用回退画面。
- 存储失败时不修改草稿，并显示明确错误。

媒体 CRUD：

- 作品：新增、查看、改名、排序、删除，数量 1–6。
- 封面：本地文件或路径/URL，支持预览、替换、删除和焦点调整；默认同步 `poster`、`coverImage`、`posterSrc`。
- 短片：新增、查看、改名、更新来源、排序、删除；`videoSrc` 同步为第一个有效短片。
- 音乐：本地文件或路径/URL，支持试听、替换和删除。
- 新选入的未授权媒体默认状态为 `placeholder`，继续显示 `PLACEHOLDER MEDIA`。

## 3. 动效与视觉实现

### 3.1 画框吸附

- 当前画框根据鼠标位置产生明确的 X/Y 吸附、X/Y 轴倾斜和轻微 Z 轴前移。
- 相邻画框使用约 45% 强度，远端画框约 18%，保留空间层次。
- 使用弹簧速度和阻尼；鼠标离开后带轻微惯性回到轨道。
- 最大参数也不能让活动画框离开主要构图区或覆盖左侧标题。
- 控制台实时修改时平滑过渡，不跳变。

### 3.2 网络形态切换

- 保留 12 个节点，每个作品 ID 确定性获得一套位置和连线拓扑。
- 默认五个作品使用明显不同的云团、弧线、螺旋、扇形、环形形态；自定义作品由 ID 哈希生成稳定形态。
- 每次真实封面切换只触发一次变形。
- 节点从当前可见位置沿带 Z 轴拱起的曲线路径移动；网络组同时进行 yaw、pitch 和纵深运动。
- 旧连线淡出，新连线淡入；海报连接线在中段减弱，结束后重新连接活动海报。
- 快速连续切换从当前插值位置重新定向，不闪回、不并发。
- reduced-motion 下取消 Z 轴拱线和整体旋转，只保留短淡变。

### 3.3 字体层级

主页目标：

- 中文主标题 `clamp(58px, 5.2vw, 100px)`。
- 当前编号 15–17px；英文标题 15–19px；类型年份 11–12px。
- `ENTER MIX` 14px；品牌、GALLERY、SOUND 11–13px；底部提示 10px。
- 海报编号 `clamp(34px, 2.8vw, 52px)`；作品名 12px；署名约 9.5px。

详情目标：

- 英文主标题 `clamp(54px, 4.6vw, 78px)`。
- 顶部作品编号和类型 18–23px；中文标题 14px；简介 14–17px；INFO 14px。
- HUD 11px；Prev/Next 编号 13px、作品名约 15.5px、计数 10px。
- INFO 标题 `clamp(52px, 4.5vw, 76px)`；简介 19px；正文 15.5px；小标题 10.5px；素材说明 10px。
- 1280×720 下仍不得小于主标题 52px、详情正文 14px、INFO 正文 15px，且不得相互遮挡。

### 3.4 INFO 播放状态

- 打开 INFO 时只暂停作品切换控制器，不暂停 WebGL 渲染器和背景视频。
- 当前短片继续播放，结束后继续进入下一片段并循环。
- BGM 状态不变；关闭 INFO 后不重载视频、不回到第一片段。
- 渲染器只在 PLAY、页面隐藏、上下文丢失或销毁时暂停。
- 同步修改 `requestRendererPair()` 和 `visibilitychange` 中的暂停判断。

### 3.5 PLAY 墨滴

- 墨色层裁切在 PLAY 圆形内，配合轻量 SVG 位移滤镜。
- pointerenter 记录鼠标相对位置；延迟后从该点扩散并填满圆形，文字和箭头变为暖白。
- pointermove 让墨滴原点缓慢跟随。
- pointerleave 时向原点收缩，并先拉伸压缩再弹性恢复。
- 延迟完成前离开时取消动画，不闪烁。
- 键盘聚焦从圆心触发；点击仍立即打开播放器；触摸不依赖 hover。
- reduced-motion 下只做快速颜色切换。
- 控制台调整参数时，当前滤镜强度和动画速度即时更新，不跳回初始帧。

### 3.6 运动曲线与前后穿插补充

- 主页封面切换开始时使用可调起始冲量，结束时由可调弹簧和阻尼回弹；不能硬跳或机械停止。
- 动态网络的浮动速度、鼠标牵引、变形起始、回弹、阻尼和封面前景穿插深度都由控制台调节。
- 每次网络变形必须有少量节点和连线经过活动封面前方，其余节点保留在后方，形成明确但不过度遮挡内容的三维穿插。
- 详情转场的滚动回弹、阻尼、行波强度、行波频率、逐行延迟和纵深推进都必须真实进入控制器或着色器。
- PLAY 墨滴在 pointerleave、blur 和快速重复进入/移出后必须完全退场；闲置状态不能残留黑点或滤镜像素。

## 4. 验收清单

自动检查必须覆盖：

- 控制台跨路由、Escape、未保存状态、保存、撤销、组重置。
- range/number 双向同步和实时渲染。
- 作品、海报、短片、音乐 CRUD。
- IndexedDB 素材刷新恢复、删除释放、缺失回退和存储错误。
- 鼠标移动后的画框位移、倾斜、纵深达到可测阈值。
- 每次封面切换只产生一次网络形态变化；中段存在 Z 轴运动；最终拓扑正确。
- 快速连续切换无闪回、白屏、并发时间线或页面错误。
- INFO 打开后背景视频时间继续增加并能自动换片。
- PLAY 墨滴的延迟、鼠标原点、扩散、回弹、键盘和 reduced-motion。
- 控制台、INFO、PLAY、Escape 的状态优先级稳定。
